# Maple trackers

Two small tools that read your own MapleStory status bar / inventory over
GeForce NOW and show a live dashboard in your browser.

| Folder | What it tracks | Dashboard |
|---|---|---|
| `exp tracker` | EXP/hour and %/hour (last 5/10/15/30 min), today's EXP, level and time to next level | http://127.0.0.1:8765 |
| `mesos tracker` | Mesos/hour (last 5/10/15/30 min), today's mesos, mesos spent — keep your inventory open | http://127.0.0.1:8766 |

Run either one with its `run.bat` (Windows, Python 3). Each folder has a
`README.txt` with details.
